# Descripción del proyecto

**Organizador Personal** es la estructura base de una aplicación pensada para
administrar tareas y notas personales.

El propósito de este repositorio no es implementar la lógica de la aplicación,
sino dejar preparado el entorno de trabajo y el flujo de versionado y
colaboración: proyecto organizado en Visual Studio Code, entorno virtual de
Python, dependencias registradas en `requirements.txt`, historial de commits en
Git y publicación y colaboración en GitHub mediante fork y Pull Request.

A futuro, la aplicación permitiría al usuario registrar sus pendientes, darles
seguimiento y guardar notas asociadas.
