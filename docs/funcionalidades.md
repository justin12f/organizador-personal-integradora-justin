# Funcionalidades previstas

- **Registrar tareas.** Alta de una tarea con título, descripción y fecha límite.
- **Consultar tareas.** Listar las tareas registradas y filtrarlas por estado.
- **Modificar tareas.** Editar los datos de una tarea existente.
- **Marcar tareas como terminadas.** Cambiar el estado de una tarea a completada.
- **Registrar notas.** Guardar notas de texto libre, opcionalmente asociadas a una tarea.
- **Recordatorios por fecha.** Avisar de las tareas cuya fecha límite está próxima o vencida.
